# FiguredIt growth checklist

Based on the [Ship It Growth Guide](https://shipit-student-setup.build989979.chatgpt.site/growth/). Treat the guide's traffic and revenue targets as experiments, not promises. Do not publish fabricated customers, outcomes, or testimonials.

## Completed in the product

- Clear B2B ICP positioning, one public demo, visible Free/Starter/Pro pricing, and a single signup path already exist.
- Public pages have titles and canonical URLs; `robots.txt` and `sitemap.xml` exist. A practical ICP guide with a fictional worked example is now linked from the site.
- Simple Analytics tracks public pages and the existing signup, upload, analysis, export, waitlist, and pricing events. Do not attach names, email addresses, or uploaded rows to these events.

## Owner steps, in order

1. **Search visibility:** In [Google Search Console](https://search.google.com/search-console), check whether `figuredit.in` is already a verified Domain property. The site also has an existing HTML verification tag, but a Domain property requires the exact DNS TXT value supplied by Google. If missing, add that value in Namecheap DNS, verify, then submit `https://figuredit.in/sitemap.xml` and inspect the new ICP guide URL. [Google's Domain property instructions](https://support.google.com/webmasters/answer/34592?hl=en).
2. **Bing:** [Import the verified Search Console property](https://www2.bing.com/webmasters/help/add-and-verify-site-12184f8b) into Bing Webmaster Tools, then confirm the sitemap appears. Do not create a second DNS record unless the import fails.
3. **Customer evidence:** Ask five B2B founders or sales leads to try one real lead-list task. Record the first blocker, whether they reached a useful result, and the wording they used for the problem. Ask permission before publishing any quote or case study.
4. **Content:** Publish one worked example per week only when it answers a real customer question. The new guide is the first example. Link each piece to the appropriate demo or signup step and check indexing in Search Console.
5. **Distribution:** Choose five relevant communities or directories with an actual B2B founder/sales audience. Read each submission rule, use accurate screenshots and plan limits, submit manually, and record approval and referral visits. Avoid bulk submissions and bought backlinks.
6. **Outreach:** If the target buyers use X or LinkedIn, share the fictional guide and demo with a clear sample-data label. Ask for feedback on the workflow; do not claim proven uplift, conversion, or customer results without evidence.
7. **Review weekly:** Compare public visits by source, signup completion, first useful analysis, return usage, and operating cost. Fix the most repeated user blocker before increasing outreach or paid spend. Keep existing prices until actual conversion and cost data support a change.
